MultiOme — multiplex network medicine for gene groups

Bring your own network layers and gene sets. MultiOme finds the layers in which a gene group is modular, walks only those layers, weighted by how modular the group is in each, to rank candidate genes, and measures retrieval with paired cross-validation. Paper behaviour (Buphamalai et al., Nat Commun 2021) is the default; modern options are flags.

Input

Layers + gene groups

  • Folder of edge lists, one file per layer (tsv/csv); header, delimiter auto-detected
  • optional layers.tsv: tags, description
  • Gene sets: GMT, long or wide table
  • new HGNC symbol normalisation + coverage report

read_multiplex · read_gene_groups

Step 1

Layer relevance (LCC modularity)

  • paper z vs 1000 random same-size sets
  • paper p = 1−Φ(z), BH over all group×layer, q<0.05, ≥10 genes, LCC≥5
  • option null="degree" · p_value="empirical"

modularity_table → significant layers + z per group

Step 2

Informed multiplex random walk

  • paper only significant layers; P[i,j]=min(1,zi/zj)/L
  • paper restart r=0.7 from seed genes; score = mean over layers
  • option coupling="present" · geomean · uniform/softmax weights
  • new matrix-free, matches the R code to 1e-6

informed_rwr → ranked candidate genes

Step 3

Cross-validated retrieval

  • paper 10 folds; groups of 20–2000 genes; AUROC per fold
  • new same folds for every configuration
  • new layers chosen from training genes only; protocol="paper" uses the full group, as published

retrieval_cv → per-fold AUROC, top-k

Output

Tables + figures

  • modularity heatmap · layer relevance
  • CV performance · candidate ranking
  • modularity.tsv, ranking_*.tsv, cv_*.tsv, coverage.tsv

What deviates from the original code

newNo leakage in CV: layers and weights come from training genes only. The published protocol inflated median AUROC by about 0.005.
newGene symbols normalised to HGNC. The shipped layers mixed SEPT7 and SEPTIN7; unmatched memberships drop from 154 to 70.
newSeeded and reproducible. The R code's seed=144 was never applied.
optionDegree-preserving null: the uniform null inflates z. For the largest group, PPI z drops from 10.5 to 2.5.
optionEmpirical p-values: the normal approximation is anticonservative for small LCCs.
optionPresent-only coupling: removes the pass-through copies of genes absent from a layer.
